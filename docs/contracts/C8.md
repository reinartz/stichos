# C8 — Payload Budget Contract

**Owner:** REN (rendering)
**Status:** frozen at M1
**Version:** 1.0.0

## Scope

This contract defines the payload budget constraints for images returned by stichos tools
to the calling vision LLM.

## Constraints

### Image Count
- Maximum **20 image blocks** per tool response.
- Exceeding this triggers stricter per-image dimension limits.

### Image Dimensions
- Maximum **2000 pixels per side** (width or height).
- Images are pre-resized to fit within this limit, preserving aspect ratio.

### Token Estimation
- Visual token count per image: `⌈width/28⌉ × ⌈height/28⌉`
- Standard vision tier limit: 1568 tokens per image (768px long edge).
- High-res tier limit: 4784 tokens (2576px long edge).

## Enforcement

- `stichos` tools MUST enforce these limits before returning image data.
- Requests exceeding the budget are rejected with a `LIN-B-001`/`LIN-B-002` diagnostic.
- The `enforce_budget()` function clamps oversized dimensions and counts blocks.
