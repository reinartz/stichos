# C10 — Policy + Taint Contract

## Scope
EditPolicy and TaintMark types used by the executor and tool responses.

## EditPolicy
- Part-class allow-list (glob patterns)
- Destructive-op default-deny
- Empty policy → nothing allowed

## TaintMark
- Propagates document text taint through IR into tool responses
- Response envelope carries `tainted: true` + source part

## Conformance
- Type + serde tests
- Deny-by-default proven in unit tests
