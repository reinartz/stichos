# C10 — Policy + Taint Contract

## Status: **v1 frozen** (2026-09-14)

> This contract is frozen. Changes require updating this document and the
> conformance checklist in full before any code modification.

## Scope

EditPolicy, TaintMark, ResponseEnvelope, ExecuteResult.tainted_parts/policy_violations — types used by the executor and tool responses for security gating and provenance.

## Producer (gp-core types)

### EditPolicy

- **Module**: `policy.rs`
- **Purpose**: Part-class allow-list with destructive-op default-deny.
- **Fields**:
  - `allowed_parts: Vec<String>` — glob patterns (supports `*`, `**`, `?`) for matching part URIs. Empty vec = deny-by-default.
  - `denied_actions: Vec<DeniedAction>` — actions always denied regardless of allow-list. Defaults to `[DeletePart, MacroPartWrite, ExternalRelAdd]`.
  - `max_parts_modified: Option<usize>` — optional safety cap on parts modified per edit.
- **Semantics**:
  1. Empty `allowed_parts` → every part denied (deny-by-default).
  2. Part not matching any `allowed_parts` pattern → denied.
  3. Actions in `denied_actions` → always denied.
- **Serde**: `skip_serializing_if` on `max_parts_modified`; `DeniedAction` uses `#[serde(rename_all = "snake_case")]`.

### DeniedAction

- Enum variants: `DeletePart`, `MacroPartWrite`, `ExternalRelAdd`, `UnknownAction`.
- Serializes as snake_case strings (`"delete_part"`, `"macro_part_write"`, `"external_rel_add"`, `"unknown_action"`).

### TaintKind

- Enum variants: `DocxText`, `PdfText`, `Unknown`.
- Serializes as snake_case: `"docx_text"`, `"pdf_text"`, `"unknown"`.

### TaintMark

- **Module**: `policy.rs`
- **Fields**:
  - `tainted: bool` — whether the response carries taint.
  - `source_part: Option<String>` — the part that introduced taint; omitted when `None` (`skip_serializing_if`).
  - `kind: TaintKind` — classification of taint source.
- **Propagation**: flows through IR → `ExecuteResult.tainted_parts` → `ResponseEnvelope.taint`.

### ResponseEnvelope

- **Module**: `policy.rs`
- **Fields**: `success: bool`, `taint: Option<TaintMark>`, `diagnostics: Vec<Diagnostic>`, `journal_id: Option<String>`, `fidelity_budget: FidelityBudget`.
- **Builders**: `success()`, `failure()`, `with_taint()`, `with_diagnostic()`, `with_journal_id()`, `with_fidelity_budget()`.

### ExecuteResult

- **Module**: `executor.rs`
- **New fields for C10**:
  - `tainted_parts: Vec<String>` — source parts with extractable text content.
  - `policy_violations: Vec<PolicyDenial>` — parts denied by edit policy.
- **Methods**:
  - `with_taint(mark: TaintMark)` — propagates taint source into `tainted_parts`.
  - `policy_refuse(format, violations)` — creates refusal result with `policy_violations`.

### PolicyDenial

- **Fields**: `part: String`, `reason: String`, `diagnostic_code: String`.
- **Codes**: `POL-D-002` (policy denied), `POL-D-003` (max_parts_modified reached).

### PolicyCheckResult

- **Fields**: `allowed: Vec<String>`, `denied: Vec<PolicyDenial>`.

### SurgicalPatchExecutor

- **Policy enforcement** (`check_policy`): evaluates ops against policy pre-apply.
- **Taint extraction** (`extract_taint`): detects format-specific content markers in source bytes.
  - OOXML: `word/`, `xl/`, `ppt/` OPC markers.
  - PDF: `%PDF-` binary marker.

### ExecutorConfig

- **Optional policy**: `policy: Option<EditPolicy>`. `None` → permissive default with deny-by-default destructive ops.

## Consumer conformance

- **Executor** consults policy via `check_policy()` before executing.
- **Taint flows** from `extract_taint()` → `ExecuteResult.tainted_parts` → response envelope.
- **Dry-run mode** carries taint and IR diff information.
- **Refused formats** (ODF/PDF) carry no taint (empty `tainted_parts`).
